# GameplaySystems

Unity/C# gameplay systems, puzzle mechanics and level-authoring tools by **Erham Safa Aksoy**: a Unity developer with 1.5+ years of professional mobile-game experience at Brew Games.

## Projects

### 🧩 [PuzzleFramework](https://github.com/GameplaySystems/PuzzleFramework)
A reusable Unity package for grid-based puzzle games. It includes board and occupancy systems, swept-collision drag movement, a JSON level pipeline and a shared live level-authoring core, all covered by automated Edit Mode and Play Mode tests. A mechanic moves into the package only after a second game shows the abstraction is worth reusing.

### 🐱 [Drop The Cat](https://github.com/GameplaySystems/DropTheCat)
A grid-based collection puzzle with drag movement, color and capacity rules, obstacles and a custom JSON-backed level editor. Built on PuzzleFramework.

▶️ [Gameplay](https://youtube.com/shorts/QkdXlsT2eZM) · 🛠️ [Level editor](https://youtu.be/4jjk2oQ1NC4)

### 🟦 [Color Block Escape](https://github.com/GameplaySystems/PuzzleFramework-ColorBlockEscape)
A sliding-block puzzle with collision-aware multi-cell movement, matching colored exits, a countdown timer, gameplay UI and level-authoring tools. It's the second game built on PuzzleFramework.

▶️ [Gameplay](https://youtube.com/shorts/NqHJ5-KoL2E) · 🛠️ [Level editor](https://youtu.be/kO0bnt70fH8)

### ⚔️ [BagManagementBattler](https://github.com/GameplaySystems/BagManagementBattler)
A 2D bag-management auto-battler (in development) with grid inventory, adjacency-driven soldier production and wave-based combat.
